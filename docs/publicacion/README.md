# Publicación en tiendas

Documentación de trabajo para **DaminatoFit** y **PupiApp**. No registra trámites hechos: no hay cuentas de desarrollador cargadas en este repositorio, no hay fichas enviadas y no hay aprobaciones.

Las reglas de Google Play y App Store cambian. Cada ítem marcado como «verificar» hay que contrastarlo con la documentación oficial vigente el día del envío.

| Documento                                              | Para qué sirve                                 |
| ------------------------------------------------------ | ---------------------------------------------- |
| [google-play.md](./google-play.md)                     | Android                                        |
| [apple-app-store.md](./apple-app-store.md)             | iOS                                            |
| [pupiapp.md](./pupiapp.md)                             | PupiApp como app independiente                 |
| [privacidad-y-legales.md](./privacidad-y-legales.md)   | Privacidad, cuentas, contenido de entrenadores |
| [recursos-y-documentos.md](./recursos-y-documentos.md) | Gráficos, capturas, credenciales de revisión   |
| [checklist.md](./checklist.md)                         | Lista antes de presentar                       |

Identificadores actuales del código (`com.example.daminatofit` y `com.example.pupiapp`) son de desarrollo. Hay que reemplazarlos antes de una ficha real.

La Fase 6 agrega avisos, mensajes y la base de notificaciones push. El envío real a teléfonos **no está habilitado**: faltan el proyecto Expo, el token de acceso y las credenciales de Apple y Google. Ver `docs/fase-6-comunicacion.md`.
